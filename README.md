# Bright Spark Electrical Services

## 1. Project Title

Bright Spark Electrical Services Website

---

## 2. Project Description

Bright Spark Electrical Services is a basic business website created for an
electrical services company.

The website provides information about the company, the services offered,
and ways for customers to get in contact with the business.

The website was designed to have a simple, professional and easy-to-use
layout.

---

## 3. Purpose of the Website

The purpose of the website is to create an online presence for Bright Spark
Electrical Services.

The website allows visitors to:

- Learn about the electrical business
- View the services provided
- Find contact information
- Learn why they should choose the business
- Send an enquiry using the contact form
- View Bright Spark Electrical Services images

## Design Aesthetic

The design aesthetic of the Bright Spark Electrical Services website is **simple, professional and modern**, while still being suitable for a beginner-level website. The design was created to represent an electrical services business and make the website easy for customers to understand and navigate.

### Colour Scheme

The website uses a combination of **dark navy blue, bright yellow, white and dark grey**.

* **Navy blue** is mainly used for the navigation bar, hero section and footer. It gives the website a professional and trustworthy appearance.
* **Yellow** is used for headings, buttons, borders and important details. It represents electricity and connects with the Bright Spark branding.
* **White** is used for the main content sections to keep the website clean and easy to read.
* **Dark grey** is used for supporting sections, particularly the services area, to create contrast between different parts of the website.

### Layout

The website uses a **clear section-based layout**. The main sections include:

* Home
* About Us
* Services
* Why Choose Us
* Contact Us
* Footer

The navigation bar is positioned at the top of the website so users can quickly move to different sections.

The home section uses a larger heading and image to immediately introduce the business. The services are displayed in individual boxes, making each service easy to identify and read.

### Images

The actual **Bright Spark Electrical Services images provided for the project** are used throughout the website. No AI-generated images were used. The images help make the website more connected to the actual business and add visual interest to the page.

### Typography

The website uses a simple **Arial font**. This was chosen because it is clean, professional and easy to read on both computers and mobile devices.

Headings are larger and use the navy blue or yellow colour to make important information stand out.

### Buttons and Interactive Elements

The website uses yellow buttons with navy blue text to make important actions easy to notice. When the user moves their mouse over navigation links or buttons, the colours change to provide basic visual feedback.

### Responsive Design

The website was designed to work on different screen sizes. A CSS media query was added so that the layout changes when the website is viewed on a smaller screen such as a mobile phone.

For example, the service boxes change from multiple columns into a single-column layout on smaller screens.

### Overall Aesthetic

Overall, the design focuses on being **professional, clean, simple and easy to navigate**. The navy blue and yellow combination reflects the electrical industry and Bright Spark branding, while the white and dark grey sections provide contrast and prevent the website from looking overcrowded.

The aesthetic was also improved from the previous version by reorganising the structure, improving the layout, adding clearer sections and making the website more visually consistent.
